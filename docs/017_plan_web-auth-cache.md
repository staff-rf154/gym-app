# План 017 — кэш авторизации web-admin на 10 часов

## Цель

Не требовать повторного запроса профиля при перезагрузке web-admin в течение
10 часов, не сохраняя токены в localStorage.

## Шаги

1. [x] Добавить в `web-admin/src/store/auth.ts` чтение/запись профиля
   в localStorage с TTL 10 часов и автоочистку по истечении.
2. [x] При восстановлении сессии в `web-admin/src/router.tsx` пропускать
   `/auth/me`, если профиль взят из валидного кэша; access получать через
   refresh-cookie.
3. [x] Очищать кэш при logout и при неудачном refresh.
4. [x] Собрать web-admin (`pnpm build`) и проверить lint.
5. [x] Зафиксировать результат и обновить `docs/readme.md`.

## Критерии готовности

- После перезагрузки страницы в течение 10 часов нет запроса `/auth/me`.
- Access-токен отсутствует в localStorage/sessionStorage.
- По истечении 10 часов кэш недействителен, сессия восстанавливается заново
  через refresh-cookie либо пользователь разлогинивается.
- Logout очищает кэш.
- `pnpm build` и `pnpm lint` проходят.

## Вне рамок

Остальные пункты очереди 017 из `docs/016_result_tz-disagreements.md`
выполняются отдельными шагами.
