# 038 — Задание: скорость, PDF-таблицы, бейджи, чат с ресепшеном

Дата: 2026-11-16

## Исходная формулировка

> 1. очень медленно все грузится при переходе по разделам и особенно долго
>    обновляется календарт
> 2. экспорт данных в приложении делать в табличном виде
> 3. если есть сообщение или уведобмление нужно выделять ставить циыру сколько
>    сообщений
> 4. чаты появился чат с тренером но с рецепшен по залу нету

## Сжатая формулировка

1. Ускорить загрузку разделов mobile и обновление календаря тренировок клиента
   и тренера.
2. Экспорт данных в mobile формировать таблицей в PDF.
3. Показывать количество непрочитанных сообщений/уведомлений на элементах
   навигации.
4. Добавить клиенту чат с ресепшеном своего зала (сейчас есть только чат
   с тренером).

## Уточнения пользователя

- «Табличный экспорт» — формировать таблицу в PDF (не CSV и не таблица
  на экране).
- Чат с ресепшеном — использовать ресепшен зала клиента, без нового типа чата
  и без миграции БД.
- Работы по задаче 038 разрешены.

## Критерии готовности

- Месяц календаря клиента и тренера загружается облегчённым ответом без
  упражнений и результатов; детали дня подгружаются при открытии дня.
- Раздел «Тренировки» не грузит все годы при открытии, а запрашивает только
  выбранный период.
- PDF веса и упражнений формируется таблицей (проверено, реализовано в 037).
- На вкладке «Чаты» и на иконке чатов тренера видна цифра непрочитанных;
  бейдж уведомлений сохраняется.
- Клиент может открыть чат с ресепшеном своего зала; ресепшен видит и ведёт
  этот чат в web-admin.
- Backend e2e, mobile analyze/test, web-admin lint/build проходят.
- Обновлены `docs/readme.md`, `docs/038_tests_*`, `docs/038_result_*`.
