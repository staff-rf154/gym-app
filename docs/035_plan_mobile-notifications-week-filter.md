# 035 — План: уведомления при запуске и «Текущая неделя»

## Цель

При запуске mobile показывать непрочитанные уведомления, хранить в inbox
события тренировок/сообщений/чатов/питания, по умолчанию выставлять текущую
неделю во всех фильтрах периодов mobile и web.

## Согласовано

- Баннер + счётчик непрочитанных при запуске.
- События сохраняются в inbox (миграция + backend), тап ведёт в раздел.
- «Текущая неделя» — новый период, значение по умолчанию; Пн–Вс по TZ.
- Область: mobile (тренер и клиент) + web-admin (отчёты).

7. [x] Web: текущая неделя по умолчанию в трёх отчётах.

## Критерии готовности

- После входа баннер «У вас N новых уведомлений», счётчик в колокольчике.
- В inbox есть события тренировок/сообщений/чатов/питания с типом; тренер
  и клиент видят свои; тап открывает тренировку или чаты.
- Во всех периодных фильтрах mobile и отчётах web по умолчанию текущая
  неделя (Пн–Вс).
- Регресс: ручные рассылки ADMIN работают, push не дублируется.
