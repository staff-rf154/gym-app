# Задание 016 — согласование расхождений и обновление ТЗ

## Исходная формулировка
«по расхождениям давай в режиме диалога приимим решение и изменим ТЗ»

## Сжатая формулировка
Обсудить раздел 2 `docs/015_disagreements_audit.md`, зафиксировать решения
по каждому пункту в режиме вопрос-ответ и отразить их в `docs/tehzadanie.md`.
Код по решениям менять только если это явно потребуется.

## Источник расхождений
`docs/015_disagreements_audit.md`, раздел 2 (12 пунктов) + спорный сценарий
админских замеров веса.

## Ограничения
- Решения фиксировать в `docs/verdikt2.md` (вопрос + ответ).
- ТЗ менять только после ответа пользователя.
- Если решение требует кода — вынести отдельным пунктом, не смешивать с ТЗ.
