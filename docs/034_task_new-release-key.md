# 034 — Новый release-ключ по RUSTORE_KEY.md

Дата: 2026-11-15
Статус: согласовано

## Исходная формулировка

> давай создадим новый ключ согластно инструкции RUSTORE_KEY.md

## Сжатая формулировка

1. Создать новый release-keystore по `docs/RUSTORE_KEY.md` вместо текущего
   `/opt/compose/keyAPP/app-key.keystore`.
2. Сгенерировать ключи `sign` (подпись приложения) и `upload` (подпись AAB),
   RSA 2048, срок 36500 дней.
3. Сохранить резервную копию старого keystore.
4. Экспортировать PEM-сертификат upload-ключа.
5. Переключить `mobile/android/key.properties` на новый upload-ключ.
6. Пересобрать и проверить APK/AAB.

## Согласованные решения

- Старый ключ заменяется новым; резервная копия старого сохраняется.
- Пароли задаёт владелец; в репозиторий и документацию не попадают.
- PEPK-ZIP для RuStore формируется отдельно по команде из RuStore Консоли
  (нужен `encryptionkey`).
- Смена ключа означает, что обновления уже установленных сборок со старой
  подписью потребуют процедуры смены ключа в RuStore.

## Критерии готовности

- Новый keystore содержит `sign` и `upload`; старый сохранён как backup.
- `upload_cert.pem` экспортирован.
- APK/AAB подписаны новым ключом, versionCode 9, адрес
  `https://demogym.staff-rf.ru:3000`.
- `docs/034_tests_*` и `docs/034_result_*` заполнены.
