# 033 — Консолидация документации и единое ТЗ

Дата: 2026-11-15
Статус: согласовано

## Исходная формулировка

> проанализируй проект и все что есть в docs/ и создай полноценное техзадание
> с планом разработки и планом приемки и обнови корневое readme удали все
> ненужные файлы с docs они все должны войти в техзадание чтобы не допускать
> багов и дороботок только измени адрес мобильного приложения на
> https://demogym.staff-rf.ru порт 3000 создай инструкцию для получения ключа
> описаясь на RuStore:
> https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/new-version-app/upload-aab#upload-sign-key
> https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/app-publication-aurora/dev-certificate/generate-csr

## Сжатая формулировка

1. Проанализировать проект и всю документацию `docs/`.
2. Создать единое техническое задание: функциональные и нефункциональные
   требования, модель данных, API, план разработки, план приёмки, тест-кейсы.
3. Включить в ТЗ все решения, ограничения и исправленные дефекты из
   исторических файлов, чтобы исключить повторение багов и доработок.
4. Обновить корневой `README.md` под фактическое состояние проекта.
5. Удалить исторические файлы `docs/`, оставив ТЗ, инструкцию по ключу,
   ER-модель и описание API.
6. Изменить адрес мобильного приложения на `https://demogym.staff-rf.ru:3000`.
7. Создать инструкцию получения ключа подписи на основе двух страниц RuStore.
8. Пересобрать APK/AAB с release-ключом `/opt/compose/keyAPP/app-key.keystore`.

## Согласованные решения

- Оставить в `docs/`: `TZ.md`, `RUSTORE_KEY.md`, `er.md`, `api.md`,
  а также файлы задания 033 (`033_task_*`, `033_plan_*`, `033_tests_*`,
  `033_result_*`).
- Адрес API: `https://demogym.staff-rf.ru:3000` (порт 3000, как в задании).
- Сборка: APK + AAB, подпись release-ключом из `/opt/compose/keyAPP`.
- Пароль/alias ключа запрашиваются у владельца, в репозиторий не попадают.
