# Задание 022 — завершение интеграции Redis

## Исходная формулировка

Пользователь: «закончи последнее задание».

Уточнение: незавершённой осталась начатая после задания 021 интеграция
Redis (`backend/src/redis/` создан, `ioredis` установлен, но модуль не
подключён). Пользователь подтвердил вариант «Доделать Redis»: подключить
`RedisModule`, перевести throttler на Redis, добавить кеш справочников
и отчётов с инвалидацией, тесты и документацию.

## Сжатая формулировка

Завершить интеграцию Redis: распределённый throttler, кеш справочников
(залы, упражнения, продукты, цели) и отчётов с инвалидацией при изменении
данных через API; конфигурация Docker Compose; e2e-проверки.

## Критерии готовности

- `RedisModule` подключён в `AppModule`, `ThrottlerModule` использует
  `RedisThrottlerStorage`.
- При недоступном Redis приложение работает: throttler и кеш переходят
  на in-memory fallback/no-op.
- Справочники и отчёты кешируются с TTL.
- Любая изменяющая операция API инвалидирует связанный кеш.
- Backend собирается, e2e-тесты зелёные.
- Изменения зафиксированы в `docs/022_*` и `docs/readme.md`.
