> тренер работает только индивидуально все тренерровки назначаются только
> индивидуально каждому клинету так же и питание все индивидуально данные не
> могут перемешиваться. но одновременно могут быть несколько паралельно
> клиентов заниматься данные не должны перемешиаться нужно все перепроверить
> как web так и мобильный клиент и все исправить и если требуется перевыпустить
> мобильное приложение то перевыпускай. так же проверить экспорт PDF
> привязывется к адресу сервера оказанного в настройках. экспорт должен
> выполнятся в табличную форму в мобильном клиенте нижние кнопки нужно немного
> сузить текст не вмещвется в ширину и происходит перенос на новую строку.
> так же нужно в мобильном клиенте и на web запустить чаты сейчас там пусто
> нечего не отображается нужно согластно ТЗ все сделать после выполнения всего
> нужно обновить корневой readme в низу поставить месяц и год и все отправить
> на github.

## Сжатая формулировка

1. Проверить и обеспечить изоляцию данных клиентов и тренеров в web-admin,
   mobile и backend: тренировки, питание, замеры, отчёты и PDF не должны
   смешиваться; параллельные клиенты не мешают друг другу.
2. PDF-экспорт: запрашивать по адресу сервера из настроек, выводить данные
   таблицей; исправить ошибки доступа и единицы измерения.
3. Мобильный клиент: нижнее меню — уменьшить текст/ширину, исключить перенос
   подписей на новую строку.
4. Чаты в mobile и web-admin: согласно ТЗ (1:1, REST + Socket.IO,
   непрочитанные, блокировка) — сейчас список пуст и нет создания чатов.
5. Пересобрать мобильное приложение при необходимости.
6. Обновить корневой README (внизу месяц и год) и отправить изменения на GitHub.

## Критерии готовности

- Найденные нарушения изоляции (IDOR PDF для RECEPTION, подмена `admin_id`,
  выдача чужих тренировок/замеров/питания тренеру) закрыты и покрыты e2e.
- PDF формируется таблицей, корректные единицы и период, доступ только к своим
  клиентам; mobile передаёт `client.id` и использует адрес из настроек.
- Нижнее меню mobile не переносит подписи на узких экранах.
- Чаты создаются/открываются в mobile и web-admin, список и история работают,
  непрочитанные отмечаются.
- Мобильное приложение пересобрано с увеличенным `versionCode`.
- README обновлён, изменения отправлены в GitHub.
