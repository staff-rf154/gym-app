# План 021 — мягкое удаление тренеров

## Цель

Сохранить историю при удалении тренера и исключить вход архивного
пользователя, не ломая существующие связи и отчёты.

## Шаги

1. [x] Схема: `Trainer.isActive`, `Trainer.archivedAt`; миграция.
2. [x] `TrainersService.remove` → архивирование + отзыв токенов +
   деактивация связей; списки с фильтром/флагом `include_archived`.
3. [x] Auth: запрет login/refresh для архивного тренера.
4. [x] Web-admin: статус, подтверждение «Архивировать», показ архива.
5. [x] E2E: архив, скрытие из списка, вход запрещён, история сохранена.
6. [x] `docs/021_tests`, `docs/021_result`, `docs/readme.md`.
