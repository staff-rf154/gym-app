# Задание 019 — пагинация списков

## Исходная формулировка

«начинай» (продолжение очереди 017, пункт «пагинация»).

## Сжатая формулировка

Ввести единый контракт `page`/`limit` и ответ `items/total/page/limit`
для списков клиентов, тренеров, тренировок, чатов и уведомлений;
обновить web-admin и mobile под новый формат.

## Основание

`docs/tehzadanie.md`, раздел 5: `page` с 1, `limit` по умолчанию 20,
максимум 100, ответ содержит `items`, `total`, `page`, `limit`.
