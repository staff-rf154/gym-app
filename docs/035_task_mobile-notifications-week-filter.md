# 035 — Уведомления при запуске и период «Текущая неделя»

Дата: 2026-11-15
Статус: выполнено

## Исходная формулировка

> Мобильное приложение сделать запрос при запуски показывать уведомление
> и отображать уведомления о тренеровках, сообщения, чаты в фильтрах
> по периодам везде выставлять текущая неделя это касается всего и тренера
> и клиента добавить это в TZ

## Сжатая формулировка

1. Mobile: при запуске (после авторизации) запрашивать уведомления и показывать
   пользователю непрочитанные уведомления.
2. Отображать в уведомлениях события о тренировках, сообщениях и чатах.
3. Во всех фильтрах по периодам у тренера и клиента по умолчанию выставлять
   «Текущая неделя».
4. Зафиксировать поведение в `docs/TZ.md`.

## Открытые вопросы

- Показывать при запуске in-app баннер/диалог или системное уведомление?
- Должны ли события тренировок/чатов сохраняться в списке уведомлений
  (сейчас там только ручные рассылки ADMIN, а push о событиях не сохраняется)?
- «Текущая неделя» — добавить новый период в фильтры тренировок и сделать
  значением по умолчанию; неделя Пн–Вс по TZ пользователя?
- Ограничить область только mobile (тренер и клиент) или менять ещё web-admin?

## Ответы (2026-11-15)

- При запуске: in-app баннер «У вас N новых уведомлений» + счётчик.
- Источники: сохранять события тренировок, сообщений/чатов и питания в inbox
  (миграция и backend), тап ведёт в раздел.
- Период: «Текущая неделя» (Пн–Вс по TZ пользователя) во всех фильтрах
  тренировок тренера и клиента по умолчанию; в PDF — неделя.
- Область: mobile + web-admin (отчёты — текущая неделя по умолчанию).
