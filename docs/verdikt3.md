# Verdikt 3 — глобальные шаблоны тренировок

Дата: 2026-11-13. Задание: `docs/023_task_global-workout-templates.md`.

**Вопрос 1. Кто создаёт глобальные шаблоны и кто их видит?**
Ответ: ADMIN создаёт глобальные (для всех залов) и шаблоны конкретного зала;
RECEPTION создаёт только шаблоны своего зала. TRAINER видит глобальные,
шаблоны своих залов и свои личные.

**Вопрос 2. Как оформлять дефолтную конфигурацию?**
Ответ: идемпотентный seed. Повторный запуск не создаёт дублей; дефолтные
шаблоны определяются по `defaultKey`.

**Вопрос 3. Куда добавлять популярные тренажёры?**
Ответ: в каждый существующий зал при seed и в демо-залы при загрузке
демо-данных; дубли по имени в зале не создаются.

**Вопрос 4. Что значит «мягкое удаление»?**
Ответ: `isActive = false` + `archivedAt = now()` для шаблонов и упражнений.
Записи остаются в БД; история тренировок и связи шаблонов не удаляются.
