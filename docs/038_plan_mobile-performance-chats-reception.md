# 038 — План: скорость, PDF-таблицы, бейджи, чат с ресепшеном

Дата: 2026-11-16

## Цель

Ускорить mobile, привести экспорт к PDF-таблице, показать количество
непрочитанных и добавить чат клиента с ресепшеном зала.

## Шаги

1. Backend: облегчённый календарь
   - [x] `GET /client/workouts/calendar` — только id, даты, статус, зал,
         тренер, время; без items/exercise/equipment/result.
   - [x] `GET /trainer/workouts/calendar` — то же для тренера с фильтрами
         client_id/gym_id.
   - [x] Маршруты `calendar` объявить до `:id`.
2. Mobile: календарь и тренировки
   - [x] Клиентский календарь использует облегчённый ответ месяца.
   - [x] Экран дня догружает полные тренировки дня при открытии.
   - [x] Тренерский календарь использует облегчённый ответ месяца.
   - [x] «Тренировки» клиента запрашивают только выбранный период.
   - [x] Инвалидация только текущего месяца, а не всей семьи провайдеров.
3. Mobile: бейджи
   - [x] Провайдер суммы непрочитанных чатов.
   - [x] Бейдж на вкладке «Чаты» клиента.
   - [x] Бейдж на иконке «Чаты» тренера.
   - [x] Обновление бейджа после прочтения/нового сообщения.
4. Backend: чат с ресепшеном
   - [x] RECEPTION может быть участником CLIENT_ADMIN.
   - [x] Клиент без admin_id получает ресепшен своего зала, иначе ADMIN.
   - [x] Проверка зала при явном admin_id.
   - [x] Web-admin: пункт «Чаты» и маршрут для RECEPTION; создание чата
         только для ADMIN.
5. Mobile: чат с ресепшеном
   - [x] Кнопка «Написать ресепшену» в разделе «Чаты».
   - [x] Создание/открытие CLIENT_ADMIN.
6. PDF
   - [x] Проверить, что PDF веса и упражнений — таблица (реализовано в 037).
   - [x] Зафиксировать в readme, что новый backend должен быть развёрнут:
         контейнер от 2026-11-14 не содержит изменений 037 от 2026-11-16.
7. Проверки и документация
   - [x] Backend e2e (календарь, чат с ресепшеном).
   - [x] `flutter analyze`, `flutter test`.
   - [x] web-admin lint/build.
   - [x] `docs/readme.md`, `docs/038_tests_*`, `docs/038_result_*`.
8. Сборка и деплой
   - [x] Mobile версия 1.0.9 (11), APK/AAB.
   - [x] Пересобрать и перезапустить backend/web-admin.
   - [x] Проверить health backend, web-admin и статус миграций.

## Критерии готовности

- Календарь не передаёт вложенные упражнения за месяц.
- Бейджи показывают количество непрочитанных.
- Клиент и ресепшен видят общий чат.
- Проверки зелёные, документация обновлена.
