# Задание 024 — сохранение авторизации web-admin при перезагрузке

## Исходная формулировка

«web при нажатии crtl+r выкидывает и прихоодится авторизовываться хотя надо
чтобы 10 часов авторизация активная была»

## Сжатая формулировка

После `Ctrl+R` в web-admin пользователь не должен разлогиниваться в течение
10 часов. Причина — refresh-cookie с флагом `Secure` на HTTP-стенде: браузер
её не сохраняет, поэтому восстановление сессии через `/auth/refresh` падает.

## Требуемый результат

- Backend выставляет `Secure` у refresh-cookie только при HTTPS
  (по `X-Forwarded-Proto`/`request.secure`).
- На HTTP refresh-cookie сохраняется и `Ctrl+R` восстанавливает сессию.
- Существующий клиентский кэш профиля на 10 часов сохраняется.
- Поведение на HTTPS не меняется.
