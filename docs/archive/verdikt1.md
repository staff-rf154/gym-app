# Verdikt 1 — шаги плана для «Тренажёров» и дашборда

Дата: 2026-11-11

## Вопрос

Какой шаг плана разрабатывает `/protected/equipment` (раздел «Тренажёры») и дашборд? Сначала делаем весь функционал, баги исправляем позже, кроме блокирующих разработку.

## Ответ

- `/protected/equipment` — шаг **1.16 «Equipment»** в `docs/plan1.md:86`. Реализован только вложенный маршрут `/protected/gyms/:id/equipment`; верхнеуровневый пункт меню был заглушкой (**BUG-2.20**, `docs/bug2.md:209`).
- Дашборд — шаг **1.14 «каркас»** в `docs/plan1.md:84`, страница была заглушкой (**BUG-2.20**). Отдельного шага с полным функционалом дашборда в плане нет; ТЗ описывает его только как экран (`docs/tehzadanie.md:151`).
- Backend не имеет агрегирующего эндпоинта дашборда и общего `GET /admin/equipment`; есть `GET /admin/gyms/:gymId/equipment`.

## Решение

Делаем frontend на текущих API: выбор зала, CRUD тренажёров, вложенный режим, дашборд с карточками и быстрыми переходами. Backend не меняем. Баги исправляем после завершения функционала; блокирующих не обнаружено.
