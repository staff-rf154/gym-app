# Task 11 — универсальный поиск по всем полям

Дата: 2026-11-12
Запрос (исходная формулировка): «нужно в тренеры, клиенты, цели, рецепшен, залы,
тренажеры, упражнения, продукты предусмотреть поиск по всем полям интерактивный
после ввода 3 символа добавь в планы и начни выполнять».

Сжатая формулировка: добавить в web-admin на страницы «Тренеры», «Клиенты»,
«Цели», «Ресепшн», «Залы», «Тренажёры», «Упражнения», «Продукты» интерактивный
поиск по всем полям карточки; фильтрация начинается с 3-го введённого символа,
без нажатия Enter.

Ограничения:

- поиск по всем отображаемым/хранимым полям строки (включая вложенные объекты и
  массивы: цель, залы, тренеры и т.п.);
- до 3 символов список показывается без фильтрации;
- регистр не важен;
- существующие серверные фильтры (тип, группа мышц, выбор зала) сохраняются.
