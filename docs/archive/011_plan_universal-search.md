# Plan 11 — универсальный поиск по всем полям

Дата создания: 2026-11-12
Источник: `docs/011_task_universal-search.md`

## Цель

Интерактивный поиск по всем полям на страницах web-admin: «Тренеры», «Клиенты»,
«Цели», «Ресепшн», «Залы», «Тренажёры», «Упражнения», «Продукты».

## Принятые решения

- Фильтрация выполняется на клиенте по уже загруженным строкам: списки грузятся
  целиком, без пагинации, поэтому серверные изменения не нужны.
- Поиск охватывает все поля объекта рекурсивно (строки, числа, булевы значения,
  вложенные объекты и массивы).
- Порог — 3 символа после `trim`; до порога показываются все строки.
- Общий хук `useTableSearch` в `web-admin/src/hooks/useTableSearch.ts`, чтобы не
  дублировать логику на восьми страницах.
- Существующие фильтры «Тип»/«Группа мышц» у упражнений и выбор зала у
  тренажёров сохраняются и комбинируются с поиском.

## Критерии готовности

- На всех восьми страницах есть поле поиска.
- При вводе 1–2 символов список не фильтруется, с 3 символов фильтруется
  интерактивно при каждом изменении.
- Поиск находит совпадения по любому полю, включая вложенные.
- `pnpm build` и `pnpm lint` в `web-admin` проходят.
