## Сжатая формулировка

Исправить в мобильном приложении невозможность тренера создать тренировку,
перепроверить контракты mobile ↔ backend после изменения логики и собрать
новую релизную версию приложения.

## Признаки проблемы

- Тренер не может дойти до создания тренировки либо получает ошибку.
- Логика backend менялась: цели, залы, связи клиент–тренер, тренировки.

## Критерии готовности

- Тренер открывает список клиентов и карточку клиента.
- Тренер создаёт тренировку через «Назначить тренировку».
- `flutter analyze` и `flutter test` проходят.
- Собраны новые APK и AAB с повышенной версией.
