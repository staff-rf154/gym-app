# bug5 — RuStore не извлекает ключ из pepk_out.zip

Дата: 2026-11-15
Задание: 034

## Симптом

При загрузке `pepk_out.zip` (2.93 KB) в окне «Загрузка подписи приложения»
RuStore Консоль показывает:

> Не удалось извлечь закрытый ключ из архива. Проверьте архив и попробуйте
> ещё раз.

## Проверки

- ZIP целый: `unzip -t` — OK; внутри `encryptedPrivateKey` (1801 байт) и
  `certificate.pem` (1229 байт).
- `certificate.pem` соответствует ключу `sign`:
  SHA-256 `19:CA:96:...:8F:A3`.
- Ключ `sign` — RSA 2048, срок 36500 дней, пароль совпадает с хранилищем.
- PEPK запускался из каталога с `pepk.jar`, JDK 17.
- Без `--include-cert` PEPK пишет **сырой** ключ (1.8 KB), а не ZIP, поэтому
  этот вариант для RuStore не подходит; архив с сертификатом восстановлен.

## Гипотезы

1. `encryptionkey` устарел или относится к другой сессии/приложению: RuStore
   не может расшифровать ключ.
2. `pepk.jar` скачан из старого окна и не совместим с текущей сессией.

## Следующие шаги

1. Открыть окно «Загрузка подписи приложения» заново.
2. Скачать `pepk.jar` из этого окна.
3. Скопировать **новую** команду с актуальным `encryptionkey`.
4. Перегенерировать `pepk_out.zip` и загрузить его вместе с
   `upload_cert.pem`.
5. Если ошибка повторится — проверить, не опубликовано ли приложение ранее
   со старой подписью `a.ivanov`; тогда требуется процедура смены ключа.
