# Тесты 020 — SQL-агрегация отчётов

Дата: 2026-11-13

## Команда

```bash
cd backend
set -a; . ../.env; set +a
export DATABASE_URL="postgresql://gym:${POSTGRES_PASSWORD}@127.0.0.1:5432/gym"
pnpm test:e2e -- reports
pnpm test:e2e
pnpm build
```

`DATABASE_URL` задаётся явно: в корневом `.env` его нет, в контейнере
переменную подставляет Docker Compose.

Первый прогон отчётов дал 3 падения: тесты фильтров ADMIN/ТРЕНЕР
вызывали тяжёлые отчёты без `from`/`to`. После добавления периода
и тестов «без периода → 400» все отчёты зелёные.

## Что проверено

- attendance: динамика по day/week/month, итоги и уникальные клиенты,
  фильтры зала/тренера/клиента, период.
- equipment-usage: итоги, типы, оборудование, клиенты, динамика,
  фильтры и период.
- trainers: показатели тренеров, фильтры зала/тренера, период.
- Отсутствие периода → 400 после проверки прав (чужой зал → 403).
- Регрессия остальных модулей полным e2e-прогоном.

## Примечания

- `PushService: FCM credentials not found` — ожидаемое предупреждение
  без `secrets/fcm.json`, push отключён, тесты не затрагивает.
- Тесты используют локальную БД и удаляют созданные фикстуры.
