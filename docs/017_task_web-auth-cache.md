# Задание 017 — кэш авторизации web-admin на 10 часов

## Исходная формулировка

«начни реалиизацию. самым первым шагом на web кэш авторизации 10 часов»

## Сжатая формулировка

Реализовать в web-admin кэширование авторизационной сессии на 10 часов:
при перезагрузке страницы пользователь и его роль восстанавливаются без
повторного запроса `/auth/me`; access-токен в localStorage не сохраняется
и по-прежнему живёт только в памяти, обновляясь через httpOnly refresh-cookie.

## Уточнение

Пользователь выбрал вариант «сессию без токена в storage»: в localStorage
хранится только профиль (`user_id`, `role`, `name`, `phone`, `timezone`)
и срок действия кэша. Токены не сохраняются.
